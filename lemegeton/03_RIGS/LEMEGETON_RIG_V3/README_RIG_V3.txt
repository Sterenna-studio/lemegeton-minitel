LEMEGETON RIG V3
================
Cette passe prépare le rig de production :
- pivots mécaniques documentés
- contrôleurs dédiés
- IK réel dans le fichier Blender via contraintes
- tête pilotable
- doigts indépendants
- vue éclatée d'inspection
- viewer web accompagnant
- launcher anti-CORS

Le GLB reste une base glTF skinnée ; les contraintes IK Blender ne sont pas des
animations glTF tant qu'elles ne sont pas bakées. La séparation sémantique
fine du mesh Meshy reste la dernière étape de validation géométrique.

Lancer le viewer :
WEB_VIEWER/START_VIEWER.bat
