- **6 documents** ont été adaptés exprès, pour les nouveaux chemins et les liens :
  `AGENTS.md`, `PASSATION_AGENTS.md`, `PIPELINE_TRAVAIL.md`, `README.md`,
  `08_AUDIT/SOURCE_VERIFICATION.json` et `08_AUDIT/validate.ps1`.
- Les fichiers de l'application ont évolué normalement avec les PR.
- **Tous les binaires sont intacts**, au SHA-256 près (GLB, Blender, images, vidéos, NPZ).

Les binaires du personnage (environ 2,9 Go) n'existent qu'à un seul endroit,
ce dossier. C'est un choix assumé de l'utilisateur : une seule copie de travail
pour les gros fichiers, sans copie externe.

## Limites connues et points ouverts

1. **Firmware autonome : corrigé.** Il avait bien le même cisaillement que
   `LibZyra.js` (`ac6bbcd`). Il reste à le flasher sur le dongle : aucune carte
   n'était branchée au moment du correctif. Il faudra ensuite cocher, dans le plan
   de validation, la vérification « formes symétriques ».
2. **Yeux Alien du firmware**, hors périmètre. Ils emploient des octets qui ne
   sont pas des paires miroir (`0x62` / `0x65`), et deux octets hors de la plage
   mosaïque (`0x59` / `0x5C`). Leur rendu est à regarder sur le terminal avant
   toute retouche.
3. **Demi-cellule Zyra** : les traits sont centrés sur la colonne 20, le contour
   sur la colonne 20,5. Ce décalage vient du dessin d'origine, et il est conservé.
4. **Terminatel 255** : aucune source publique n'a été trouvée. La page
   Documentation le dit.
5. **Playwright** : le Chromium embarqué n'est pas installé, les tests tournent sur
   Edge (`channel: 'msedge'`).
6. **ESLint : traité.** Passage d'ESLint 9 (déprécié) à 10, avec
   `eslint-plugin-react-hooks` 7 et `globals` 17. Les règles du React Compiler
   ajoutées par la v7 ne sont pas activées : le projet ne l'utilise pas, et les
   textures Three.js y sont modifiées impérativement par conception.
7. **Branches locales : traité.** Les branches fusionnées ont été supprimées dans
   les checkouts locaux.
