## Limites connues et points ouverts

1. **Firmware autonome** : `Minitel_Face_Autonomous.ino` emploie le même ordre
   `G1_TOP = 0x70` / `G1_BOTTOM = 0x2F` que l'ancien `LibZyra.js`. Selon la norme
   G1, il devrait afficher le même cisaillement. Pourtant, l'utilisateur ne l'a pas
   observé sur le terminal. À vérifier sur le matériel, qui fait foi. Le firmware
   n'a pas été touché.
2. **Demi-cellule Zyra** : les traits sont centrés sur la colonne 20, le contour
   sur la colonne 20,5. Ce décalage vient du dessin d'origine, et il est conservé.
3. **Terminatel 255** : aucune source publique n'a été trouvée. La page
   Documentation le dit.
4. **Playwright** : le Chromium embarqué n'est pas installé, les tests tournent sur
   Edge (`channel: 'msedge'`).
5. **Branches locales** : les branches fusionnées sont encore présentes dans les
   checkouts locaux. On peut les supprimer sans risque.
6. **Sauvegarde des binaires** : voir le point d'attention plus haut.
