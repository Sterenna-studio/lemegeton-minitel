# Références photographiques — Minitel Telic Alcatel Terminatel 255

58 fichiers conservés, classés en **18 vues** et **5 catégories**. Chaque dossier de vue regroupe toutes les tailles et tous les formats disponibles de la même photographie.

Le nom historique du dossier parent est conservé. Le marquage visible porte la graphie **TELIC ALCATEL**.

## Retrouver un élément

- `01-vues-ensemble` : terminal avec clavier, trois dispositions.
- `02-ecran-et-coque` : écran, profil, finition marbrée et grille latérale.
- `03-arriere-et-accessoires` : arrière, câbles, connectique et boîtier bleu.
- `04-clavier-et-combine` : clavier, dessous, touches et combiné.
- `05-marquages` : inscriptions techniques, TERMINATEL 255 et TELIC ALCATEL.

## Convention de nommage

`categorie/numero-vue/element__largeurxhauteur__lTAILLE.extension`

Exemple : `02-ecran-et-coque/04-ecran-face/ecran-face__1482x1434__l1600.webp`.

Les dimensions sont celles du fichier réel. `l500`, `l960` et `l1600` conservent le palier du nom source ; **l1600 ne garantit pas 1600 pixels**. Ces paliers indiquent les variantes de taille, pas une mesure de qualité visuelle. Les variantes PNG/JPEG/WebP sont conservées sans conversion, retouche ni recompression.

[Inventaire CSV](inventaire-images.csv) : ancien nom, nouveau chemin, vue, description, dimensions, palier source, format, taille en octets et SHA-256. Tous les fichiers ont été vérifiés par SHA-256 avant/après déplacement.
